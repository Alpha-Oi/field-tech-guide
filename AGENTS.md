# Гайд для мастеров ИТ-ремонта (field-tech-guide)

Пошаговый гайд для выездных мастеров ИТ-ремонта: одна страница для телефона (этапы и шаги с отметками, «Памятка на заявку», «Прайс и акт»), её текстовая версия и записка техдиру. Тексты и данные компании отделены от кода: движок собирает всё из `guide/content/` и профиля компании.

## Команды

| Команда | Что делает |
|---------|------------|
| `python guide/build.py` | собрать демо в `dist/` |
| `python guide/build.py --profile private/profile.json --pricelist private/pricelist.json --out private/dist` | собрать настоящий гайд (`private/` в git не входит) |
| `python guide/build.py --check` | проверить контент, профиль и прайс |
| `python -m unittest discover -s guide/tests -t .` | тесты |
| `python tools/check_public.py` | проверка репозитория на утечку внутренних данных |

Проверка целиком: `python -m unittest discover -s guide/tests -t . && python guide/build.py --check && python tools/check_public.py && python tools/make_charts.py --check`. После правки контента график пересобирается командой `python tools/make_charts.py`. На Windows команда Python — `python`.

## Правила

- Только стандартная библиотека Python; страница — один файл без внешних подключений; данные попадают в DOM только через `textContent` и `createElement`.
- Всё, что принадлежит компании (названия приложений, ники, ссылки, цены, проценты), — переменные профиля. В публичных файлах их значений нет. Внутренние документы (`*.docx`, `*.pdf`, `*.jpg` и им подобные) в git не добавляются.
- Тексты гайда — на «ты», коротко, честно: без давления на клиента, без завышения цен и дробления услуг, без имитации работы, без нелицензионного ПО.
- Схема данных контента, профиля и прайса описана в `README.md` и в `guide/profiles/VARS.md`.
