## Как добавить запись

1. Возьмите следующий номер и назовите файл `NNNN-короткое-название.md`.
2. Опишите решение по образцу: заголовок, статус и дата, затем разделы «Контекст», «Решение», «Последствия» и «Рассмотренные альтернативы» (две-три, с причиной отказа). Пишите коротко и по-русски; каждая запись — не больше шестидесяти строк.
3. Не переписывайте принятую запись, когда решение меняется: добавьте новую, а в старой смените статус на «заменено записью NNNN».
4. Добавьте строку в оглавление выше.

В записи не должно быть ничего, что принадлежит компании: названий приложений, ников, имён, ссылок на магазины, цен и процентов. Правила и проверка — в [privacy.md](../privacy.md) и [CONTRIBUTING.md](../../CONTRIBUTING.md).
