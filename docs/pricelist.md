# Прайс и панель «Прайс и акт»

Прайс — отдельный JSON-файл, не часть текстов гайда. Сборка кладёт его в данные страницы под ключом `pricelist`, а страница строит по нему панель «Прайс и акт»: мастер выбирает оказанные услуги, страница считает таблицу для бланка акта. Если прайса нет, ключа нет и панель скрыта. Общая схема работы сборки — в [architecture.md](architecture.md), как собрать гайд с настоящим прайсом — в [deploy.md](deploy.md).

Прайс — обычный текст: переменных профиля `{{…}}` и разметки в нём нет (метка в прайсе — ошибка проверки). Все примеры ниже вымышленные.

## Схема

Корень файла — объект:

| Поле | Обязательно | Что это |
|---|---|---|
| `title` | да | название прайса |
| `currency` | да | знак валюты, например `₽` |
| `note` | нет | пояснение под названием, строка |
| `items` | да | список позиций; может быть пустым, если есть матрицы |
| `matrices` | нет | таблицы «модель × услуга» |

### Позиции (`items`)

| Поле | Обязательно | Правило |
|---|---|---|
| `id` | да | уникален среди позиций |
| `no` | да | номер как в прайсе, **строкой**: бывает `"14.1"` |
| `group` | да | группа для навигации: список в панели делится по группам |
| `name` | да | название услуги |
| `kind` | да | вид цены, см. ниже |
| `price` | да | целое число от 0 для `fixed` и `from`; `null` для `ask` и `na` |
| `description` | нет | пояснение, строка (может быть пустой) |

Виды цены `kind`:

| Вид | Что значит | `price` |
|---|---|---|
| `fixed` | точная цена | целое число от 0 |
| `from` | «от N» | целое число от 0 |
| `ask` | «уточнять»: цену называют на месте | `null` |
| `na` | «недоступно»: услугу добавить в акт нельзя | `null` |

### Таблицы «модель × услуга» (`matrices`)

Строки таблицы — модели, столбцы — услуги, в ячейке цена.

| Поле | Обязательно | Правило |
|---|---|---|
| `id` | да | уникален среди таблиц |
| `title` | да | название таблицы |
| `note` | нет | пояснение, строка |
| `columns` | да | столбцы-услуги: `id` (уникален в таблице) и `name` |
| `rows` | да | строки-модели: `id` (уникален в таблице), `label` и `prices` |

`prices` в строке — объект «`id` столбца → ячейка». Ключи — только существующие `id` столбцов; отсутствующий ключ — то же, что `null`. Значение ячейки:

| Ячейка | Что значит |
|---|---|
| целое число от 0 | точная цена; в акте её можно только снижать |
| `"ask"` | цену называет мастер на месте |
| `null` (или нет ключа) | недоступно: услугу для этой модели отметить нельзя |
| `{"hint": "…", "from": N}` | цену вводит мастер; `hint` — непустая подсказка, она показывается рядом с полем цены; `from` — целое число от 0 или `null`: нижняя граница, ниже которой страница предупреждает |

Формулу вроде «500 ₽ + 500 ₽/клавиша» записывают объектом с подсказкой и без границы: `{"hint": "500 ₽ + 500 ₽/клавиша", "from": null}`.

### Пример


## Проверка

Сборка проверяет прайс и печатает ошибки по-русски с указанием места (позиция, таблица, строка, столбец). Проверяются:

- есть `title`, `currency` и список `items`; в прайсе есть хотя бы позиция или таблица; неизвестные поля — ошибка;
- `id` позиций уникальны, `id` таблиц уникальны, а `id` столбцов и строк уникальны внутри таблицы;
- `no` — непустая строка; есть `group` и `name`; `description` — строка;
- `kind` — один из `fixed`, `from`, `ask`, `na`; для `fixed` и `from` `price` — целое число от 0, для `ask` и `na` — `null`;
- в ячейке — целое число от 0, `"ask"`, `null` или объект только с полями `hint` (непустая строка) и `from` (целое число от 0 или `null`); ключи в `prices` — только существующие столбцы;
- нигде нет меток `{{…}}`.

Эти же проверки делает функция `validate_pricelist` в `guide/build.py`.

## Как подключить свой прайс

Прайс подключается флагом `--pricelist`:

```bash
python guide/build.py --check --pricelist private/pricelist.json
python guide/build.py --pricelist private/pricelist.json --out private/dist
```

```powershell
python guide/build.py --check --pricelist private/pricelist.json
python guide/build.py --pricelist private/pricelist.json --out private/dist
```

Первая команда только проверяет файл и печатает число позиций и таблиц, вторая собирает гайд. Без флага берётся демо-прайс `guide/profiles/demo-pricelist.json`. Флаг `--no-pricelist` собирает гайд без прайса, а вместе с `--pricelist` он даёт ошибку.

Настоящий прайс компании лежит в `private/pricelist.json`, в git он не попадает; подробности — в [privacy.md](privacy.md). Чтобы дополнить демо-прайс, см. [CONTRIBUTING.md](../CONTRIBUTING.md).

## Как работает панель «Прайс и акт»

Кнопка «Прайс и акт» стоит рядом с «Памяткой на заявку»; панель создаётся, только если в прайсе есть позиции или таблицы.

**Выбор.** Позиции ищутся по названию (слово в любом месте) и по номеру (с начала номера), их можно отфильтровать по группе; описание раскрывается. Кнопка «Добавить» кладёт позицию в «Выбрано»; позицию «недоступно» добавить нельзя. Для таблицы сначала выбирается модель, затем отмечаются услуги: в «Выбрано» попадают строки вида «Замена батареи — модель». Услуга, которая уже выбрана, второй раз не добавляется.

**Список «Выбрано».** У каждой строки:

- **количество** — целое число от 1 (до 999); меняйте его, только если услуга оказана столько раз;
- **цена за единицу** — для `fixed` стоит цена из прайса, и её можно только снижать: цена выше прайса — ошибка «по закону цена не может превышать прайс». Для `from` в поле стоит цена «от», мастер вписывает фактическую. Для `ask` и ячейки-объекта мастер вписывает цену сам (больше нуля), подсказка из `hint` стоит рядом с полем; цена ниже `from` даёт предупреждение, итог оно не блокирует;
- **сумма строки** — цена × количество; пока в строке есть ошибка, сумма не считается;
- **Гарантия** — текст, необязательно;
- кнопка удаления строки; «Очистить» убирает всё после подтверждения.

**Итог.** Расчёт идёт целыми рублями:

- «Стоимость услуг» — сумма строк;
- «Стоимость комплектующих» — число, которое мастер вводит вручную (по чекам); скидка на них не действует;
- «Скидка, %» — целое число от 0 до 100, считается от стоимости услуг; сумма скидки округляется до рубля, «половина» — вверх;
- «К оплате» = стоимость услуг − скидка + комплектующие.

Пока в строках есть ошибки или список пуст, итоги не считаются, а страница говорит, что мешает.

**Текст для бланка.** Кнопка «Скопировать список для бланка» даёт строки «1. Название — цена × количество = сумма — гарантия» и итоги. Над текстом напоминание: в бланк писать от руки красным, в пустых полях ставить прочерки, вносить только оказанные услуги.

**Данные не сохраняются.** Выбор, цены, скидка и комплектующие живут только в памяти открытой страницы и пропадают при закрытии. Ни на диск, ни в `localStorage` они не попадают.
